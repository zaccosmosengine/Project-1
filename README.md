# PROJECT // 01: NOIR

An editorial, minimalist agency portfolio template built for luxury brands and high-end creatives.

## Features
* **Editorial Aesthetic:** Deep obsidian dark mode with clean typography and gold accents.
* **Interactive Scope Builder:** A custom configurator designed for bespoke project scoping.
* **Instagram DM Dispatcher:** Seamless direct routing to `@zac.cosmos.engine`.

## Tech Stack
* HTML5, CSS3, Vanilla JavaScript.
